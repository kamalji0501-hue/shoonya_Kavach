# KAVACH Telegram credentials

This folder holds the **only** Kavach Telegram bot identity (`@kavach_batmanbot`).

- **Runtime code:** Kavach 2.0 (`run_kavach2.py` / `bat_telegram.bots.kavach2`)
- **Secrets:** `token.env` with `KAVACH_BOT_TOKEN` / `KAVACH_CHAT_ID`
- Classic Kavach code has been removed from this repo.

Do not create a separate `@kavach2_batmanbot` token for Phase-1.
