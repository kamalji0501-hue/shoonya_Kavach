System Overview

DRISHTI starts three parallel processes on bot startup. Each process has a single, well-defined responsibility that never overlaps with the others.

2

Token Reminder & Validation Flow

Core DRISHTI flow. Runs at every scheduled slot (09:00 / 15:30 / 23:00 IST). Checks if reminder should fire, asks user via interactive Yes/No, collects token, validates it using live LTP, and resets the scheduler. Repeats until token is updated.

Confirmation sent to user
Error / validation failed
Warning / reminder
Dotted loop = returns to scheduler for next slot

Market Hours Monitor & Telegram Commands

Left: Background loop active only during NSE trading hours — fires an immediate, non-suppressible alert if the connection drops. Right: Telegram commands available 24/7 regardless of trading hours.

flowchart TD subgraph MON["MARKET HOURS MONITOR - background loop"] direction TB MM(["Monitor loop\nstarts with bot"]) --> CHK{"NSE trading day?\n09:15 to 15:30 IST"} CHK -- No --> SLP["Sleep 60s\nNot trading hours"] SLP --> CHK CHK -- Yes --> FETCH["Fetch NIFTY LTP\nEvery 3600s by default"] FETCH --> OK{"Fetch\nsuccess?"} OK -- Yes --> LOG["Log: connection healthy"] LOG --> WAIT["Sleep interval"] WAIT --> FETCH OK -- No --> RETRY["Retry 3x\n5s delay, x2 backoff"] RETRY --> ROK{"Success\non retry?"} ROK -- Yes --> LOG ROK -- No --> ALT(["IMMEDIATE ALERT\nNIFTY LTP fetch failed\nError: reason\nNo quiet hours - fires now"]) ALT --> WAIT end subgraph CMD["TELEGRAM COMMANDS - 24/7 always on"] direction TB TC(["Incoming Telegram\nmessage"]) --> TYPE{"Message\ntype?"} TYPE -- "/health" --> HC["Fetch NIFTY LTP\nFetch GIFT Nifty\nCheck token age"] HC --> HR(["Health report\nToken status + time remaining\nNIFTY LTP value\nGIFT Nifty value\nBot uptime"]) TYPE -- "/ping" --> PR(["DRISHTI alive\ntimestamp IST"]) TYPE -- "Token string" --> TVF(["Go to Token\nValidation Flow\nsee Diagram 2"]) TYPE -- "Yes button" --> YB(["Please send your\nDhan access token"]) TYPE -- "No button" --> NB(["Noted\nWill remind at\nnext slot"]) TYPE -- "Other" --> UNK(["Unknown command\nignored"]) end
Immediate alert - no quiet hours, no suppression, fires instantly
/health and /ping work 24/7 regardless of trading hours or token status
Token string sent directly skips the reminder and goes straight to validation
