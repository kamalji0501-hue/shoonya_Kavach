# Coding Handoff Checklist

Use this checklist before any coding sprint.

## Requirements Clarity

- [ ] Feature objective is explicitly stated.
- [ ] In-scope and out-of-scope boundaries are documented.
- [ ] Success criteria are measurable.
- [ ] Failure behavior is defined.

## Dependencies

- [ ] Upstream/downstream dependencies are listed.
- [ ] Required configs and environment assumptions are noted.
- [ ] Ownership boundaries are clear.

## Data and Reporting

- [ ] Inputs and outputs are defined.
- [ ] Required fields and formats are finalized.
- [ ] Alerting/reporting expectations are documented.

## Implementation Readiness

- [ ] Tracker status and next action are current.
- [ ] Open questions are either resolved or explicitly parked.
- [ ] Evidence paths for validation are identified.

## Sign-off

- [ ] Ready for coding.
- [ ] Not ready (list blockers).
